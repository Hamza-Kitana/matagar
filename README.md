# VYBE

موقع متجر إكسسوارات (ساعات ذكية، سماعات، وإكسسوارات موبايل) بتجربة سكرول تفاعلية وأنيميشن 3D. فرونت إند بس (Vite + React).

## التشغيل

```sh
bun install
bun run dev
```

للنسخة النهائية: `bun run build`، والملفات بتطلع بمجلد `dist` وبتنرفع على أي استضافة ستاتيك (Netlify، Vercel، GitHub Pages).
